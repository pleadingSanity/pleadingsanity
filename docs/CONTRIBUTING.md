# Contributing to Pleading Sanity

Thank you. This house is built from lived experience and the AI family. Anyone who wants to help people rise is welcome.

**Evolution, Not Erasure.** We build on what works. We do not erase what serves.

## Quick start

The front end is pure HTML, CSS and vanilla JavaScript. No build step for the pages.

```bash
git clone https://github.com/pleadingSanity/pleadingsanity.git
cd pleadingsanity
npm install          # only needed for Netlify functions and tools
npm run dev          # serves the site at http://localhost:3000
```

Open `index.html` in a browser if you prefer. Netlify functions live in `netlify/functions/` and need the Netlify CLI to test locally.

## Before you open a pull request

1. Read the manifesto and the safety rules (Samaritans 116 123 and SHOUT 85258 stay visible).
2. Keep changes small and reversible.
3. Do not expose secrets, private journals or user data.
4. Test on a phone screen and with a keyboard.
5. Describe what you changed and why.

## Mental health first

- No stigmatising language
- Crisis numbers always easy to find
- Local-first where possible
- Forget Me must keep working
- If a change could affect someone in distress, say so in the PR

## Code of conduct (short)

Be kind. Be clear. Protect the people who use this house. Harassment, doxxing or minimising mental health struggles will not be accepted.

## Recognition

Every contribution is noted. The house belongs to the people who keep it standing.
