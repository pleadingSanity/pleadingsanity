Build with us

The house is open. Pure HTML, CSS and vanilla JavaScript. No complicated build. Clone it, run it, and help people rise from madness.

Start in five minutes

The front end needs nothing more than a browser. For the Netlify functions you only need Node.

git clone https://github.com/pleadingSanity/pleadingsanity.git
cd pleadingsanity
npm install
npm run dev

Then open http://localhost:3000. Or just open index.html in any browser.
