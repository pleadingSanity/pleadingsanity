# Self-hosted heading fonts

Used by `css/alive-20261123.css` on the sanctuary (headings, hero titles and nav). No font CDN and no tracking.

| File | Family | Weight | Licence | Project |
|---|---|---|---|---|
| `orbitron-latin-700.woff2` | Orbitron | 700 | SIL Open Font License 1.1 (`OFL-Orbitron.txt`) | The Orbitron Project Authors (Matt McInerney / The League of Moveable Type). Reserved Font Name: "Orbitron". |
| `exo2-latin-600.woff2` | Exo 2 | 600 | SIL Open Font License 1.1 (`OFL-Exo2.txt`) | The Exo 2 Project Authors (Natanael Gama). |

Both are latin WOFF2 subsets (`font-display: swap`). Body text stays on the existing system UI stack. The `anton/` folder was already in the repo and is unchanged.
