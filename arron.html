Privacy · Forget Me

Your messages and story can be saved on this device and synced with the site. Guest memory uses a private code; signed-in memory can be linked to your account. Your messages may include personal details you choose to share. Replies come from GPT, Claude or Gemini through Netlify's AI Gateway, or from Grok through xAI. If all four are quiet, you get the real help lines instead (see Privacy). Forget Me clears local Arron memory and requests deletion from the site database. If a server request fails, it is queued for retry. Provider-held data is governed by each provider’s terms. No ads or selling personal data.

How he grows

  • When you are online, the app can check for published updates in the background.
  • Shared guidance is updated through reviewed releases. Your private conversations are not automatically added to that guidance.
  • Pages saved by your browser and local tools may remain available offline. New AI replies need a connection; clearing browser data can remove saved copies.

Your privacy

  • Talking to Arron is free.
  • Memory starts on this device and can sync with the site when online. Guest memory uses a private code; signed-in memory can be linked to your account. Read how Arron and its providers process messages before sharing sensitive information.
  • No ads, no tracking, never sold.
  • Forget Me asks for confirmation, clears local Arron memory and requests deletion from the site database. If offline, the request is queued for retry; it does not delete your whole account or data held separately by other services.
